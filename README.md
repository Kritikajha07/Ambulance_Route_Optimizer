# Emergency Ambulance Route Optimizer

An interactive Emergency Ambulance Route Optimizer developed as a DAA project for Ahmedabad, Gujarat.

## Features

- Interactive Ahmedabad map
- Ambulance location marker
- Draggable ambulance location
- Emergency hospital selection
- Nearest hospital detection
- Dijkstra's Shortest Path Algorithm
- Dynamic Programming Shortest Path
- Traffic congestion simulation
- Blocked road simulation
- Automatic route recalculation
- Alternative routes
- Turn-by-turn navigation
- Algorithm benchmarking
- DAA viva guide

## Technologies Used

- React
- TypeScript
- Vite
- Leaflet
- HTML
- CSS
- JavaScript

## DAA Algorithms

### Dijkstra's Shortest Path Algorithm

Dijkstra's algorithm is used to find the shortest route from the ambulance's current location to the selected hospital.

### Dynamic Programming Shortest Path

A stage-based Dynamic Programming approach is used to calculate and compare shortest paths using optimal substructure.

## Dynamic Routing

The system simulates changing traffic conditions and blocked roads. When road conditions change, the route is recalculated automatically.

## Disclaimer

This project is an academic simulation and is not intended for real emergency dispatch.
